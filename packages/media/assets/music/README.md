# Background music tracks (Story Studio)

Drop **royalty-free / CC0** MP3s here, named by mood. Story Studio mixes the
matching track quietly under the narration when you pick that mood on the Create
page. A missing file is skipped cleanly (no error), so this is optional.

Expected filenames:

- `calm.mp3`
- `tense.mp3`
- `upbeat.mp3`
- `epic.mp3`

Sources for genuinely free tracks: YouTube Audio Library, Pixabay Music,
Free Music Archive (CC0), Incompetech (CC-BY — credit required). Do **not** put
copyrighted music here — it ships in your published videos.
